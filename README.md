# rocket-league-nitro-arena

A browser-based Rocket League-inspired arena game with:
- nitro boost driving
- friend list and match lobby flow
- host/join code system
- training arena mode
- play arena mode with scoring and boost pads

## Run it

Open `index.html` directly in a browser, or serve the folder locally:

```bash
cd rocket-league-nitro-arena
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- Blue car: Arrow keys to steer, Shift for nitro
- Orange car: WASD to steer, Space for nitro

## Features

- Friend list management
- Host a lobby and create a code
- Join a lobby with a code
- Training arena for practice
- Play arena with goals and score tracking
- Nitro boost pads around the field
